# A3 小红书原文读取助手安装说明

这套扩展同时适用于 Microsoft Edge 和 Google Chrome。写手需要在使用 A3 内容工具的同一个浏览器中安装扩展，并先登录小红书网页版。

## 安装前准备

1. 把整个 `xhs-extension` 文件夹复制到写手电脑上的固定位置。
2. 不要只复制其中某一个文件，也不要安装完成后移动或删除该文件夹。
3. 解压后确认文件夹中能看到 `manifest.json`、`background.js`、`content.js` 和 `page-bridge.js`。

## Microsoft Edge 安装

1. 打开 Edge。
2. 在地址栏输入 `edge://extensions/`，按回车。
3. 打开页面左侧或左下角的“开发人员模式”。
4. 点击“加载解压缩的扩展”。
5. 选择完整的 `xhs-extension` 文件夹，不要选择文件夹里的单个文件。
6. 在扩展列表中找到“A3 小红书原文读取助手”，确认版本为 `1.2.0`，开关为开启状态。
7. 点击“详细信息”，打开“允许访问文件网址”。A3 本地启动脚本会直接打开 `index.html`，缺少这一权限时扩展无法连接页面。
8. 确认扩展允许访问 `xiaohongshu.com`。如果 Edge 显示“站点访问权限”，允许小红书与本地 A3 页面。
9. 打开 `https://www.xiaohongshu.com/`，完成登录，并确认网页搜索可以正常使用。
10. 在同一个 Edge、同一个浏览器个人资料中打开 A3 本地网站。
11. 按 `Ctrl+Shift+R`；Mac 按 `Command+Shift+R`，强制刷新 A3 页面。
12. 进入“好奇 → 文案生成”，勾选“搜索小红书近期内容”，输入关键词后点击“读取背景资料”。

## Google Chrome 安装

1. 打开 Chrome。
2. 在地址栏输入 `chrome://extensions/`，按回车。
3. 打开右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择完整的 `xhs-extension` 文件夹。
6. 确认“A3 小红书原文读取助手”版本为 `1.2.0`，且开关已开启。
7. 点击“详细信息”，打开“允许访问文件网址”。
8. 打开 `https://www.xiaohongshu.com/` 并完成登录。
9. 在同一个 Chrome、同一个浏览器个人资料中打开 A3 本地网站，强制刷新后测试关键词搜索。

## 每次更新扩展后的操作

1. 解压新版压缩包，并用新版文件完整覆盖原 `xhs-extension` 文件夹；如果找不到原文件夹，直接在扩展管理页删除旧版，再加载新版文件夹。
2. 回到 `edge://extensions/` 或 `chrome://extensions/`。
3. 点击该扩展卡片上的“重新加载”按钮；如浏览器提示新增权限，请允许。版本应显示为 `1.2.0`。
4. 回到 A3 页面按一次刷新，再重新搜索。

## 常见问题

- 页面提示“未检测到小红书读取助手”：确认扩展详情中的“允许访问文件网址”已经开启；确认 A3 页面和小红书登录页使用的是同一个 Edge/Chrome及同一个浏览器个人资料；重新加载扩展后强制刷新 A3 页面。
- 页面仍显示“小红书搜索服务暂不可用”：这是旧页面提示。请换用最新本地测试包，关闭旧页面后重新启动，并执行一次强制刷新。
- 能打开小红书但搜索失败：先在小红书网页手动搜索一次，确认账号未掉线、未出现验证码或访问限制，再返回 A3 页面重试。
- 直接请求被小红书拦截时，1.2.0 会短暂打开一个不激活的备用标签页读取当前登录态，读取后自动关闭，这是正常行为。
- `127.0.0.1` 打不开：它指向当前写手自己的电脑。需要先在这台电脑启动 A3 本地网站，不能直接使用另一台电脑的 `127.0.0.1` 地址。
- 安装后移动了扩展文件夹：把文件夹移回原位，或在扩展管理页删除后重新“加载解压缩的扩展”。
- Safari 或 Firefox：本版本不支持，请使用 Edge 或 Chrome。

扩展只读取当前浏览器已登录的小红书网页结果，不需要把小红书密码填写到 A3 工具中。
